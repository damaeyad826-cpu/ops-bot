# ProBot OPS Discord Bot Dashboard 🛡️

لوحة تحكم تفاعلية متقدمة ومستقلة لسيرفر وبوت **OPS**، مستوحاة من تصميم Probot بميزات أمان عالية وتحكم كامل لحظي.

---

## 🚀 لماذا كان الرابط السابق يطلب تسجيل الدخول بحساب Google؟
الروابط السابقة المنتهية بـ `*.run.app` هي روابط **بيئة المعاينة الداخلية الخاصة بـ Google AI Studio**، وتتطلب بطبيعتها تسجيل الدخول بحساب Google المصرح له بتطوير المشروع.

**لجعل لوحة التحكم عامة ومتاحة للجميع ومستقلة تماماً بدون أي شاشة تسجيل دخول من Google**، يمكنك نشرها عبر **GitHub Pages** أو **Vercel** خلال دقيقة واحدة كالتالي:

---

## ⚡ الطريقة 1: النشر التلقائي عبر GitHub Pages (مجاناً 100%)

تم تجهيز ملف الأتمتة (`.github/workflows/deploy.yml`) في المشروع ليعمل فوراً:

1. ارفع المشروع إلى مستودع **Public** على GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial OPS Dashboard"
   git branch -M main
   git remote add origin https://github.com/USERNAME/ops-bot-dashboard.git
   git push -u origin main
   ```
2. في صفحة المستودع على GitHub:
   - اذهب إلى **Settings** ⚙️ ثم اختر **Pages** من القائمة الجانبية.
   - في خانة **Source**، اختر: **GitHub Actions**.
3. بمجرد انتهاء البناء (خلال دقيقة واحدة)، سيعطيك GitHub رابطاً عاماً ومباشراً:
   👉 `https://USERNAME.github.io/ops-bot-dashboard`
   **هذا الرابط يفتح لوحة التحكم فوراً وبشكل مباشر لأي شخص دون أي تحويل لـ Google!**

---

## ⚡ الطريقة 2: النشر بضغطة زر واحدة على Vercel (الأسهل والأسرع)

1. سجل دخولك على [Vercel.com](https://vercel.com) بحساب GitHub.
2. اضغط **Add New...** ثم **Project**.
3. اختر مستودع المشروع `ops-bot-dashboard` واضغط **Deploy**.
4. ستحصل على رابط مباشر وسريع جداً:
   👉 `https://ops-bot-dashboard.vercel.app`

---

## 🛠️ التشغيل المحلي على جهازك (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير المدمج مع الـ Backend
npm run dev

# أو بناء نسخة الإنتاج
npm run build
```

## ✨ المميزات المضمنة في اللوحة:
* 🎨 **تخصيص كامل للأوامر والردود:** إمكانية تعديل نصوص الأوامر، تحديد الصلاحيات والرتب لكل أمر، وإضافة أوامر جديدة.
* 🎫 **مصمم بنل التذاكر (Ticket Panel Designer):** تخصيص ألوان الأزرار، النصوص، والترانسكربت مع ميزة تحويل الصوت إلى نص (Live STT).
* 🛡️ **نظام الحماية والـ IP Whitelist:** تقييد الوصول لمالك السيرفر والإداريين المصرح لهم فقط.
* 👥 **عرض كافة رتب السيرفر الـ 21 رتبة:** مع الألوان الرسمية وتصنيفات الإدارة والأعضاء.
* 📊 **سجلات تدقيق لحظية ومراقبة لنقاط الطاقم الإداري (Staff Points).**
